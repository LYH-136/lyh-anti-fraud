# 银铃守护 · 老年人反诈学堂

面向老年群体的反诈学习与 AI 辨伪平台。用「看得懂的视频 + 猜得到的互动 + 找得到的电话」三件事，帮助老人识破当前高发的网络骗局，并通过「一个学生带动一个家庭」的家校联动机制扩大覆盖。

> 基于 uni-app（Vue 2）开发，运行到 H5 即为网页，同一套代码也可发布为小程序 / App。

---

## 功能一览

| 板块 | 说明 |
| --- | --- |
| 登录分流 | 用户 / 管理员双入口。用户端填昵称密码并选择身份（长辈、小学、初中、高中、大学、教师），管理员端独立校验 |
| 首页 | 顶部宣传视频位、一键报警入口、六大板块卡片、最新判例与预警、新作业提醒 |
| 反诈学习 | 6 类诈骗分类（刷单返利、游戏账号充值、虚假返现、虚假陪聊、冒充公检法、AI 换脸），12 节微课，自动累计学习时长，看满 80% 判定完课，课后 3 道随堂题 |
| AI 辨伪实验室 | 视频 / 语音两类判断题。作答后揭晓判定结果、AI 合成含量与破绽分析，并附真实案例分析 |
| 反诈答题 | 题库随机组卷 10 题，80 分及格，通过后可生成带编号的电子证书并导出图片 |
| 家校联合 | 教师端按学段发布作业，长辈端 / 学生端仅保留「接受作业」，实时统计参与人数与接受进度 |
| 一键报警 | 110、96110、12381、12321 四个直拨按钮，六家银行挂失电话，被骗后三步处置指引 |
| 判例与新闻 | 19 个真实司法判例（含案发地、时间、涉案金额、判决结果、防骗要点）+ 新闻与预警，支持展开阅读全文 |
| 个人中心 | 学习时长、完课数、积分、徽章、答题记录、证书 |
| 管理后台 | 数据看板（PV/UV、学习总时长、答题通过率、家校参与人数、7 日趋势、页面热度）、视频管理、内容管理、作业管理、用户列表、修改密码、重置演示数据 |

## 技术栈

- **框架**：uni-app + Vue 2（Options API）
- **UI**：uni 原生组件 + 手写 CSS，无第三方 UI 库
- **数据**：`localStorage` 本地存储，数据层集中在 `utils/store.js`，替换后端只需改这一个文件
- **图表**：内联 SVG / CSS 绘制，无图表依赖
- **素材**：微课视频由脚本逐帧生成后经 ffmpeg 编码为 H.264，封面自视频真实画面抽帧

## 快速开始

### 方式一：HBuilderX（推荐）

1. 用 HBuilderX 打开本项目目录
2. 菜单 **运行 → 运行到浏览器 → Chrome**
3. 浏览器自动打开登录页

### 方式二：发布为 H5 静态站点

菜单 **发行 → 网站-PC Web 或手机 H5**，产物位于 `unpackage/dist/build/h5`，可直接部署到任意静态托管。

## 数据说明

- 所有业务数据存放于浏览器 `localStorage`，**换设备或清理缓存后不保留**，适合演示与教学，不适合作为线上生产系统。
- `utils/store.js` 中的 `SEED_VERSION` 用于内容版本控制：升级时仅刷新视频、判例、作业等内容类数据，账号、学习记录、作业接受记录均保留。
- 接入真实后端时，只需将 `store.js` 中的读写函数替换为接口请求，页面层无需改动。
